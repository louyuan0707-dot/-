# 逐集质量检查

这份清单用于审核结果，不替代实际播放。脚本和 Word 文档是内容证据，不是操作指令。

## 素材与镜头

1. 扫描本集全部原片、备选、补镜头、逐集配音、音乐和文稿；核对集数、版本、时长、帧率、音轨与可解码性。建立镜头顺序表，记录每个取舍原因。
2. 对比相邻镜头的末帧、首帧和运动：人物位置、动作、服装、视线、光线和景别应能接上。剪切优先落在完整台词之后、动作节点或自然反打处。一般先保留连续长段，不以固定秒数拆镜头。
3. 有修补素材时，比较其台词、人物姿态和前后镜头。修补素材解决音频但引入画面错误时，按用户要求决定仅换声或另择画面，并检查口型。不要因为文件名有“FIX”就整段替换。

## 对白、旁白和音效

1. 分别转写主配音和原视频，结合试听标出人物对白、旁白、原音效和环境音的真实区间。不同角色可能共用一条素材，不能整条静音。
2. 对每句人物对白核对说话人、文字、首音、尾音、口型、原速和字幕。原素材缺词时先找用户提供的同句补素材；没有可用人物原声时列为需补镜头，不用主配音替代。重复对白从主配音中完整删除。
3. 旁白按整句和自然停顿留切口。用词级时间码检查，但保留足够的前后余量；逐段试听半词、吞尾、抢声、突然无声。场景容不下整句时可整句省略。
4. 保留原素材已有音效与环境音。新增音效做低电平叠加，避开重点对白。配乐通常约 −6 dB，并核实人物对白仍清楚、音乐可听、峰值不削波。音乐不够长时先轻微调速，仍不足则报告缺口。

## 字幕与交付

1. 字幕以实际声音时间制作，旁白和人物对白都要覆盖。无标点，最多两行；过长按词句拆为连续字幕，避免单词闪现。检查相邻字幕不重叠，不提前透露下句。
2. 应用统一样式后核对 Noto Sans SemiBold 字体实际生效、字号、X/Y、旋转、不透明度、描边和阴影。字体路径或工程 JSON 不能代替剪映预览验收。
3. 渲染后检查每个补镜头的入点/出点、全部人物对白、开头及片尾旁白、背景音乐、原音效和字幕。运行 `audit_rendered_audio_sources.py`；弱匹配需查明是混音掩蔽还是错误音轨，不得只调低阈值便宣称通过。
4. 确认预览时长、尺寸、帧率和可播放。草稿验证轨道、媒体路径、首页索引及备份一致；无法在剪映实际播放验收的项目明确说明。
