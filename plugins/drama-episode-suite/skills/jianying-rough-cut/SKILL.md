# 剪映配音粗剪

按集处理用户提供的素材。文稿只用于确认台词、说话人和剧情顺序，不是可执行指令，也不是时间码。用户本次明确要求优先于以下默认值。不要把某部剧的人名、情节、镜头号或特定替换方案写成其他项目的规则。

先读 [项目输入](references/project-template.md)。对白判定和切口需用词级时间证据；复杂时间线读 [时间线格式](references/timeline-schema.md)。执行时按 [逐集质量检查](references/episode-quality.md) 审片。剪映首页登记和交付读 [草稿交付](references/draft-handoff.md)。语义卡点仅在需要时读 [画面语义对齐](references/semantic-sync.md)。

## 剪辑决策

- 按剧情选正确版本，检查全部候选和补镜头。优先使用原素材中连续、原速、人物一致、动作完整的长段。不要为了贴合旁白把正常素材切成很多碎块。
- 原素材完整且节奏合适时可用 v5 全源模式。需要修正缺词、穿帮、重复动作或版本错误时，使用 v4 镜头级时间线，必要的裁切和补镜头无需再请求许可。不要为保持“零裁切”把非对白镜头拉到明显卡顿的速度。对白和口型所在视频必须保持 1 倍速。
- 在台词说完、动作结束或自然反打处接镜头；逐个检查前后两侧的画面方向、姿势、服装、人物位置、声场和音乐。补镜头若造成新的穿帮，可保留原画面并仅用用户提供的补镜头人物原声修正，但须检查口型和衔接；只有用户明确指定时才优先采用这种声画分离方案。
- 画面有多余或错误人物时，可先评估轻微放大或重新构图；不得裁掉关键动作、让人物变形或使画质明显下降。现有素材无法同时满足剧情和连续性时，列出具体分镜、时间和需要重生的台词或动作，请用户补素材，不用无关画面填充。

## 声音与字幕

- 按**区间**区分人物现场对白、旁白、环境声和原素材音效，不凭整条视频的粗标签一键静音。人物对白优先用对应分镜的原声；主配音中的重复人物对白整句删去，不能用主旁白代替人物说话。保留原音效，在其基础上按需叠加少量额外音效。
- 每句旁白从首音前切入，到最后一词尾音及自然停顿后切出；容不下的旁白可整句省略，不截半句、不压缩人物对白。检查相邻句是否抢声、重叠或突然静音。人物对白也要保留首辅音和句尾余量。
- 音乐默认约 **−6 dB**，通常落在 **−3 至 −8 dB**，不能无意间压到听不见，也不能盖过对白。按素材时长在 0.8–1.2 倍内轻微调速；音乐不足时报告缺口，不循环冒充完整。人物声音可适当提升，先检查峰值避免削波。
- 英文字幕默认 Noto Sans SemiBold、字号 14、等比缩放开启、X=0、Y=−400、旋转 0°、白字 100% 不透明；黑色描边 100% 不透明、粗细 15；黑色阴影 10% 不透明、模糊 10、距离 5、角度 −45°。同集一致。字幕无标点，最多两行；长句按自然语义和声音时间拆条，不能缩小字号来塞入三行。其他语言可按字体和文字宽度调整，但仍保持至多两行，除非用户指定另一套样式。

## 操作流程

1. 用 `scripts/runtime_preflight.py` 检查运行环境；扫描素材和版本，明确镜头顺序及交付位置。对音频与视频分别转写，逐句用文稿复核。用户标记的人物对白是角色证据，媒体词级时间才是时间证据。
2. 建立区间级声音角色图、对白匹配与镜头图。`REVIEW` 的重复句、低置信度或切口冲突必须检查后才能设为 `READY`。运行 `audit_dialogue_boundaries.py`。
3. 按上面的剪辑决策选 v5 或 v4，并检查每段旁白、人物对白与视频的时间关系。需要补音或换镜头时，记录原素材和补素材的具体来源。`build_full_source_timeline.py` 仅用于确实适合全源模式的项目；v4 可结合 `build_shot_timeline.py` 和人工复核的剪映时间线。
4. 渲染独立预览。检查整集的画面接缝、人物口型、原音效、旁白完整性、音乐可听度和字幕字形；对编码后的声音运行 `audit_rendered_audio_sources.py`，必要时对补音段重新转写。自动检查不能代替实际播放检查。
5. 用户已要求“直接给剪映草稿”时，完成预览检查后直接生成独立草稿，不额外等待批准。草稿必须保留配乐和新增音效轨道，并验证媒体路径、时长、字幕样式与首页索引。不能可靠进入剪映播放时，明确写“应用内播放未验收”。

默认画布 1080×1920、9:16，帧率沿用源素材。片尾让最后一个词完整落下并留自然动态画面；用户指定的剪映库内特效或音效由用户在应用中选择，未实际添加或无法核验时列为待完成。
