# 多集分镜质量门禁

多集分镜采用逐集制作、逐集验收、再合并的方式；不要一次生成大批集数后仅凭通读判断合格。每集先从原剧本建立独立声段和剧情事件清单及范围记录，再写初稿；初稿、音频锁时稿、最终 Word 稿分别检查。合并后再按集号与组号核对实际镜头、每集首尾内容、事件顺序、声段覆盖和跨集边界。对每一镜检查「人物、场景、情节、画面、微表情、动作、台词」七栏及独立画面任务。此门禁在剧梦提示词派生和任何付费生成之前执行。

## 必须判退的内容

- 占位符或待补写法，例如「待补」「TBD」「同上」「略」「后续镜头同前」「按上一镜处理」、空括号、模板字段名或省略号代替实际内容。
- 七栏中任一栏整段复制到无关镜头或其他集，人物、场景、情节与当前剧本不符；画面、微表情、动作使用不对应当前叙事进度的重复套话。
- 同一句人物对白或旁白被当作新发声内容重复起读，漏句、改词、换说话人，或把上一集的台词带到下一集。
- 连续多个镜头只有时间码变化，七栏内容基本相同，无法说明每镜新增的画面信息、反应或动作进度。
- 人物、场景、情节、画面、微表情、动作虽换了镜号却整段照搬；只替换一两个词但画面任务与动作终态不变。截图所示的同一句英文旁白跨镜重复、下一镜沿用上一镜完整场景和动作，均必须判退。

同一人物或同一场景在连续镜头中真实出现不是错误；长句跨镜也应连续播放一次。检查的是无依据重复和把「同上」当成完整分镜。跨镜台词栏可写明确的声音段编号、承接范围和「无新增台词」，但不能重复贴整句并造成多次发声。需要保留原文时以原剧本为准，不为消除重复而擅自改台词。

## 返工与放行

记录问题所在集、组、镜号、栏名、原文声段／事件 ID 和具体差异。用 `scripts/audit_storyboard.py --source source.json --ledger ledger.json` 检查原文片段拼接、事件覆盖、缺漏重读、七栏、时长和相邻镜头重复；如输出 Word，再加 `--docx` 检查可见稿是否与台账一致。自动检查是拦截器，不能替代人工判断原文清单是否漏提事件、动作是否真实变化、正反打是否越轴和转场是否有原生依据。只从原剧本重做**受影响集**或受影响组并核对相邻组；不要只用批量查找替换掩盖复制错误。未受影响且已验收的集保留原版本。若一次输出多集普遍出现模板化复制，缩小生成批次，按集重生并逐集验收，再组合交付。

只有所有目标集都没有占位符、无依据重复、漏栏和错贴，且原文与时间轴检查通过，才标记「分镜初稿通过」并进入音频锁时。锁时和创意深化后再跑同样检查并留存轮次、问题及修订结果；有警告也须记录人工判断。若重做后仍不合格，继续定位并重做受影响集；不得把失败稿提交剧梦或宣称完成。
