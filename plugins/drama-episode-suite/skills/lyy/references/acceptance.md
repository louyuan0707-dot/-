# 验收与停止规则

## 资产图

候选图必须对应资产台账的唯一名称和剧情状态；检查人物脸型、果头或发型、体型、服装与相邻集连续性。场景须为空置空间：内外景、昼夜、空间方向、可行动区域正确，色调自然且不过冷过暖，没有人物、可移动道具、文字或品牌标识；用户提供的街景只参考冷暖，不照搬地点与陈设。道具先核对该集分镜出现次数：只出现一镜的不为该集单独生图；需要独立资产时一图只出现一件，形制与用途正确，无中文、logo、旗帜、国徽、奢侈品或其他品牌／机构标志。新人物分别验收面部吸引力与角色辨识度：男性俊朗、女性漂亮，同时符合剧本年龄、身份与体型；水果人保留果人原貌，儿童保持合龄。换装不得改变已批准的身份；服装的风格、层次、材质和剧情适配性单独验收。多视角核对同一身份及服装，角色需要足以让剧梦稳定引用的视角；具体视角由该项目已有资产格式和平台能力确定。自动检查不能替代用户批准。用户未确认前，状态只能是「待用户确认」，不得上传或绑定；已上传不等于已保存引用关系。

## 分镜

逐集核对原文覆盖率、旁白与对白类型、说话人、语序、动作结果和场景连续性。逐镜严格只有七栏「人物、场景、情节、画面、微表情、动作、台词」；音效纳入相关栏，不能有无关字段或凭空新增的声音事件。多集生成的稿件还须逐集逐镜排除占位符、漏填、跨集错贴和七栏无依据重复；出现任一项则重做受影响集或组并复核，不进入音频锁时或剧梦提交。同一人物、真实连续场景及跨镜只发声一次的对白可以延续，但不能以「同上」或重复套话代替镜头内容。视觉栏不以脸或果头变色表现情绪；原文中的颜色词若属于旁白或对白，仍在「台词」栏逐字保留。镜头时长为 1–2.5 秒，组时长与组内镜头之和一致。每个声音段只起读一次，长句跨镜有延续标记；不得用原音频的总时长比例推算冒充真实逐句时间。最终声画台账须通过 `--require-audio-lock` 检查，Word 稿与台账逐镜一致，再人工验收正反打轴线和原生转场。

## 剧梦节点

生成前检查项目与集组唯一匹配、源文件版本、模型和分辨率、实际秒数、引用资产、提示词全文、组装后字符数与预计积分。确认该剧本专用限定词置于提示词最前且只出现一次，并与项目画风、原文语言及已批准资产一致；每镜正文的可见人物、场景和独立道具提及均有真实内联标签，标签身份与形象 ID 对应剧情时间和服装状态。逐镜检查回忆版男主不会绑成男二或现时版；组头对照、镜前清单与顶部卡片只作辅助。一键引用或 CLI 组装后检查没有未选择占位、姓名嵌套、错服装、重复文字或截断。派生稿只让人物对白发声，不包含旁白朗读任务；七个必需栏仍完整。已提交或远端状态未知时先查询任务，不重复提交。

## 视频

预览验证可播放且长度合理；人物原有脸型、五官、果头形状和固有颜色，以及服装、场景和道具与批准资产相符；剧情顺序、情绪反应和动作连续；人物对白原文完整、说话人正确、可听清、口型基本匹配；无新增旁白、无凭空新增台词或剧情。若出现整脸异常变灰、变青、变红、五官漂移或其他失去原貌的画面，判为不合格。任何关键项失败，保存节点与问题证据，停止自动重生成，交由用户决定下一步。
