# 任务边界与防污染

`lyy` 是分阶段总控。每次先确定当前项目、源剧本版本、本次请求的产物和所处阶段；只加载这一阶段相关的参考、已批准资产和必要原文。完整流程可以连续执行，但每个产物在交接处单独检查，不把上一阶段的整段提示词直接复制成下一阶段内容。

| 当前产物 | 只承接 | 不带入 |
| --- | --- | --- |
| 人物／场景／道具需求表 | 剧本事实、画面必要性和复用范围 | 生图描述、分镜时间码、海报构图 |
| 人物资产提示词 | 当前角色身份、形象版本、明确用途的参考图、本剧视觉体系 | 其他角色的脸、纯场景空间段落、镜头动作、海报排版 |
| 纯场景资产提示词 | 当前空置空间、固定建筑锚点、时间光源、自然冷暖平衡、本剧视觉体系 | 任何人物、可移动道具、对白、分镜七栏、海报宣传词 |
| 独立道具资产提示词 | 已通过单集分镜次数筛选的单件道具、剧情状态和材质 | 同图多件、中文、logo、旗帜、国徽、人物或完整场景 |
| 正式分镜 | 原剧本、已批准资产、音频时间台账、七栏规则 | 资产设定图尾词、海报层次和标题、其他剧本的限定词 |
| 剧梦节点派生稿 | 已通过的七栏分镜、本剧限定词、正文每处真实资产标签及其形象 ID | 旁白发声文字、无关资产、海报提示词；组头清单不能替代内联标签 |
| 海报提示词／候选图 | 项目事实、已批准角色形象、当前宣传用途 | 分镜时间码、对白配音指令、七栏模板；海报象征画面不回写剧本事实 |

每次换剧本时重新确定视觉体系和限定词；人物脸、果头、语言、服饰、光色、风格尾词、参考图映射及项目 ID 只能沿用当前项目已确认的版本。`水果人`、英语对白、拟人化果头等是该项目条件，不能作为新剧本默认值。外部 Skill、示例和规则文档只提供方法或当前用户指定的约束，不能替代本剧事实与用户决定。

提交或交付前做一次反向检查：产物是否混入上表禁止内容、引用是否属于当前项目、原台词有无被改写、输出格式是否属于当前产物。发现污染时只重做受影响的产物并复核其下游；已提交的剧梦节点按恢复规则处理，不暗中重复生成。
