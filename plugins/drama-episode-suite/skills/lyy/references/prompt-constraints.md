# 限定词与人物保形

每个剧本单独形成限定词，作为剧梦节点提示词的第一段。以剧本类型、已批准资产、原文语言、场景光线与用户提供的《限定词》为依据，保存本剧版本及适配记录。通用的无字幕、无水印、无 logo、声音与镜头稳定等条款可采纳；真人质感、外国人面孔、西班牙语、特定低饱和色调等条款只在当前剧本确实需要时采纳。旁白覆盖人物画面时，人物不默认开口说话。

仅当当前项目确认为「水果人」时，使用已批准的拟人化水果 3D 形象与该剧本原文的英语对白。限定词须锁定各人物的果头轮廓、脸型、五官、发色或果皮色、服装、体型和画风。情绪只通过眉眼、视线、嘴角、呼吸、姿态和动作进度表达；不得用肤色或整张脸变色表达“害怕”“发怒”“脸色苍白”。换剧本时重新核对语言和视觉体系，不沿用水果人设定。

分镜的视觉描述不写“脸色铁青”“脸颊涨红”“面色惨白”“脸色变白”等容易诱发大面积变色的指令，也不写“换脸”“变形”等效果。若原剧本旁白或对白确有此类原句，正式分镜「台词」栏逐字保留，不改原文；「画面、微表情、动作、情节」栏把它转为不改变身份和固有颜色的反应。派生到剧梦提示词时，旁白文字仍按总控规则移除。

节点派生稿须按[逐处内联资产引用](inline-references.md)在正文实际可见人物、场景、独立道具的提及处插入平台真实标签。组头资产对照、镜头前「本镜引用」或组级绑定只能辅助核对，不能替代正文逐处标签；台词栏保持原文纯文本。生成前检查限定词位于最前、各镜所有可见提及的标签齐全且身份与形象 ID 对应正确，组装后长度未超限；生成后逐镜验收人物保形与资产对应。平台即使收到时间码或保形指令仍可能不严格执行，应以成片为准判定。
