# 海报制作与验收（可选）

用户要求短剧封面、剧情海报或横版宣传图时才启用；不作为视频分镜通过的前置条件。沿用当前项目事实、视觉体系和已批准人物／场景形象，不从参考图顺序猜角色身份。若角色尚无获批形象，先走资产图片的验收步骤。

1. 根据用途选竖版封面、剧情海报或横版宣传图。封面强调移动端缩略图中的人物脸、关系和一眼可读的冲突；剧情海报强调主题和视觉中心；横版按投放尺寸留安全区。比例、标题及其他文字以用户或目标平台要求为准，不套用固定比例和文案。
2. 从剧本和项目事实提炼一个有依据的宣传卖点，确定主角、对手或关键关系。写清人物大小、前后层次、左右位置、朝向、视线和情绪；背景、道具、符号只服务这个卖点。避免把普通分镜画面或等大排排站当海报。海报可以有象征性排布，但不得制造剧本不存在的人物关系或事件。
3. 为每张参考图记录 `图片／形象 ID → 角色身份 → 海报位置与用途`。保持原有脸型、果头、固有颜色、体型和服装版本；风格按本剧限定词，不混用其他剧本的真人、3D 或古装词。标题按原字保留；未要求的姓名、标语、平台标识、乱码文字不添加，文字不遮挡脸和核心关系。
4. 先写可复查的海报提示词，检查剧情依据、人物身份、视觉体系、构图层级、比例、安全区和文字。需要实际图片时，查询剧梦 CLI 当前可用的生图模型与预计积分，按用户指定的「九极 2.0 促销 3」生成候选，除非用户另行指定海报模型；不猜测参数、不重复提交状态不明的任务。若用户只要提示词，到提示词交付为止。
5. 检查候选图的缩略图可读性、人物保形、服饰、场景道具、文字准确性、比例与安全区，向用户展示候选及问题。只有用户确认该版本合格后才视为正式海报；上传或绑定到剧梦须有对应任务需求，不能把海报自动当作分镜引用资产。失败时记录原因，后续重生须依照用户对该次制作的授权范围。

海报修改只调整用户点名的部分及必要的布局联动；不借机改角色基准或剧本事实。海报状态独立记录 `提示词待验 / 提示词通过 / 候选图 / 待用户确认 / 已批准 / 失败`，并保存来源版本、提示词、任务 ID、图片路径和积分。
