# 节点提交与恢复

## 批次准备

每次制作保存源剧本、各集音频、规则、限定词、正式分镜和派生提示词的版本记录：绝对路径、大小、修改时间、SHA-256；记录源集组到剧梦项目／选集／节点的显式映射，以及提示词字符数、所需资产 ID、预计积分。工作副本要保留原文件指纹，不能把副本误作新权威源。正式提交前重验关键源版本；发生暂停、文件替换或连接恢复时重新核对。若源发生变化，先列出影响范围；已经提交的节点保留历史，不自动覆盖或重做。

## 提交前门禁

目标选集、节点和已有任务先远端核对；同名旧选集或非空节点不能凭序号猜。每组完整内容放在一个节点，不把组内短镜头拆成平台节点。检查本剧限定词位于开头一次、旁白已从视频发声任务移除、人物对白原文和说话人未变、组时长与单镜时长。逐镜正文的每处可见人物、场景及独立道具提及必须有对应的真实内联标签；逐处核对角色身份、现时／回忆／换装版本与形象 ID，不把组头、镜前清单或顶部卡片当成已引用。用当前平台能力组装后检查字符数上限，并回读提交框的最终富文本，确认标签没有漏贴、错贴、截断或重复。模型、分辨率、画幅、当前节点时长及费用从当前 CLI 或页面核实；不继承上一个节点的设置结论。

本项目旁白 MP3 是锁时依据，用户尚未要求在剧梦节点绑定它。其他项目若明确需要独立音频引用，只有实际音频卡和正文中正确的真实引用才算绑定；文件名普通文字或仅有顶部卡片不算。不要把其他批量生成 Skill 的音色上传流程直接用于本项目。

## 状态和恢复

只有观察到任务 ID、节点「生成中」或等价入队证据，才标记已提交；平台显示生成完成后仍需逐镜验收，不能直接标通过。任务或点击结果不明时先查目标节点历史、任务队列和任务状态，不再次点击付费生成。记录提交时间、任务 ID、实际积分与平台取整后的时长。失败时记录具体节点、截图或可核对的证据并停止，不自动重试。

用户明确授权批量时，可预先准备全部集组清单、复用已核对的引用关系并连续处理，但每次实际付费提交仍要经过当前节点门禁。用户只授权试运行一组时，不能把批量 Skill 的「提交全部集数」当作授权。原始集组号不自动映射成剧梦界面集数；新集或新节点创建后核对编号和空白状态。当前总控的完成边界是视频已在剧梦生成且验收，默认不下载、命名或剪辑成片。
