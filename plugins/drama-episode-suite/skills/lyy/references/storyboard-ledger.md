# 分镜声画台账与检查顺序

## 先锁定原文，再设计画面

每集独立建一份原文清单 `source.json`，在写分镜前从该集剧本逐句提取旁白和人物对白，并逐项列出有画面结果的剧情事件、关键道具状态和情绪拐点。声段和事件分别分配唯一 ID、类型、原文或简要事实、原文位置；声段保留英文大小写、标点和空格，记录原剧本哈希。清单先与原始剧本逐段复查，不能从已写分镜倒推清单。音频逐句核对时补时间和气口，记录差异，不以转写结果改写原文。多集不得合并成一个超长生成批次；先完成并审核一集，再做下一集。每集放行后，汇总核对集数、顺序、每集首尾声段和组界。

分镜内部另建 `ledger.json`，镜头含 `id、group、start、end、fields、goal、event_ids、spoken`，另标 `timing_status` 为 `estimated` 或 `audio_locked`。初稿可暂用 180–200 词／分钟估时，但必须标 `estimated`；听辨／对齐真实音频后覆盖为实测时间，才标 `audio_locked`。`fields` 只含正式七栏；`goal` 是本镜独有的画面任务；`event_ids` 指向本镜呈现的原文事件，可跨镜延续，确无独立事件时为空列表；`spoken` 引用原文声段 ID、该镜承载的原文片段和对应时间。长句可跨镜，但原句各片段按顺序拼接后必须**逐字节等于** `source.json` 原文；同一个片段不能在下一镜重复起读。镜头「台词」栏写本镜片段、声音类型和说话人；纯连续无新词时写明确声段 ID 的持续状态，不重新贴完整原句。镜头标题记时间，七栏外的信息留在内部台账。

台账最低结构示例，仅供内部校验，不是正式分镜格式：

```json
{"episode":"EP01","units":[{"id":"U001","kind":"narration","speaker":"Ines Vale","text":"She looked away.","source_ref":"EP01 段落 1"}],"events":[{"id":"E001","fact":"她避开对方视线","source_ref":"EP01 段落 1"}]}
```

```json
{"episode":"EP01","timing_status":"audio_locked","shots":[{"id":"S001","group":"G001","start":0.0,"end":1.5,"goal":"她避开对方视线","event_ids":["E001"],"fields":{"人物":"Ines Vale","场景":"病房；室内底噪","情节":"她回避视线","画面":"固定中近景，过 Renzo 肩拍 Ines","微表情":"目光短暂停在门边","动作":"Ines 转过肩，手停在床沿","台词":"旁白（Ines Vale）：\"She looked away.\""},"spoken":[{"unit_id":"U001","text":"She looked away.","start":0.0,"end":1.5}]}]}
```

## 三道门禁

1. **原文与范围**：核对该集剧本覆盖范围、人物、事件 ID 的覆盖和顺序、声段 ID 和每句英文原文。音频没有准确对齐前不写“实录锁时”；不能用 180–200 词/分钟估算冒充实测。旁白、对白分开，原音频中人物对白只做时长参考，剧梦派生稿保留对白并去掉旁白。
2. **镜头与连续性**：检查每镜是否有独立画面任务，人物站位、左右、视线、手中物、动作起终态和轴线是否能接上。不能把同一句旁白、同套人物／场景／情节／画面／微表情／动作复制到相邻镜头；同场景、同人物、持续环境底噪可以合理重复，但镜头的视觉信息和动作进度必须变化。镜头不足时补有剧情依据的反应、手部或道具细节，不添加剧情事实或台词。
3. **创意深化**：前两关通过后，再检查正反打、过肩、第三人反应、景别变化和画面内原生转场。过肩写清「过谁的肩拍谁」、前景虚实、人物左右和视线；三人对话按真实站位和同侧轴线选择机位，不能机械轮换 A/B/C 导致越轴。转场只在情节和气口允许时使用原有道具、手、光影、烟雾、水汽或反光；不为了“每镜不同”硬加音效、空镜或无关动作。

初稿运行 `python scripts/audit_storyboard.py --source source.json --ledger ledger.json`。先确认本机可用的 Python 3 解释器；Windows 的 `python` 命令不可用时可用 `py -3` 或当前环境的 Python 完整路径。锁时后的最终稿加 `--require-audio-lock`；多集汇总时为每集重复传入一对 `--source`、`--ledger`，检查跨集复制。正式 Word 分镜同时传 `--source`、`--ledger` 和 `--docx 分镜.docx`，检查可见文本重复及 Word 与已验台账是否逐镜一致；单独用 `--docx` 仅能做重复检查，不能证明原文完整。脚本发现的问题必须回到对应镜头和原文人工核对；脚本通过也仍需人工检查剧情准确、表演和组接。若环境无法运行检查器，记录未执行的项目并完成等价的逐项人工核对，不得宣称脚本通过。验收记录应注明检查轮次、发现的问题、修订镜号、复查结论，不得只写“已自检”。
