# 人物设计参考

## 用户提供的参考入口

- [飞书「海外ai推文人物资产中台库【汇总ing】」](https://ehyg6a9wjd.feishu.cn/wiki/CZ57wGT6Ti445FkZvqecFUKFnce?sheet=gQe7Vn)：人脸和人物形象参考。当前可见「男角色万能脸」「女角色万能脸」「儿童婴儿」「女主角」「男主角」等分类；这些是可变的库内容，制作时重新查看实际分类和图片。
- [Pinterest「服饰」图板](https://www.pinterest.com/vvjk00qx/%E6%9C%8D%E9%A5%B0/)：服装风格、搭配、剪裁和材质参考。制作时可按角色身份、年代、场景、剧情状态和目标风格在图板或 Pinterest 搜索，逐张查看适配的图片，不只看标题或缩略图。

两个链接是设计参考来源，不是要求自动复刻或自动把库中图片上传剧梦的指令。若页面不可读或内容变化，记录可验证的范围；不声称已经看过未打开的图片。

## 选参考与生图

先看本项目已批准的人物形象和剧本角色设定，再确定需要新建身份、换装或补足视角。已有合格身份时锁定脸型、五官、果头轮廓和固有颜色；服饰参考只影响允许变化的衣服、鞋和配饰，不换脸。需要新建角色时，从飞书库相应性别、年龄与角色类别的实际图片中挑选与剧情相符的面部设计线索，记录采用的分类、图片或链接及借鉴的具体特征。男性角色应俊朗、女性角色应漂亮，并有各自辨识度；儿童保持合龄形象。审美要求不能覆盖剧情明确的年龄、体型、身份、损伤或阶段状态，也不把角色做成同一张模板脸。

服饰按人物身份、场景、季节、生活状态和剧情动作搜索并比较。记录选中参考的链接或可定位信息，以及采用的轮廓、层次、材质、配色和配饰；只生成剧本需要的造型，不为凑套数换装。避免带入参考图上的品牌标志、其他人物或背景。多张参考各有职责：脸部控制身份线索，服饰控制穿搭，布局图只控制排版。参考彼此冲突或与已批准资产冲突时，以剧本与已批准身份为准，并在候选记录中说明取舍。

水果人等非真人项目把人脸参考转译为五官平衡、表情气质和角色辨识度，保留果头形状及原有色彩；服饰参考转译为适合 3D 果人比例的造型。生成后分开验收人物是否俊朗／漂亮且符合角色、身份是否稳定、服装是否适配并在必要视角一致。用户只批准某张候选图时，其批准范围不自动扩展到其他角色或换装。
