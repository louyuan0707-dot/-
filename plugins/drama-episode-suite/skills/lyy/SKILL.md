# lyy｜剧梦旁白短剧分镜总控

## 输入与边界

接收完整剧本、每集音频、分镜规则、限定词文档、已有资产与参考图、目标剧梦项目。先确定剧名、集数、版本、项目 ID，以及已有资产和已生成节点；对源文件和已确认产物记录路径、大小、修改时间与哈希，恢复或提交前核对版本。源文件发生变化时先对比受影响集组，已提交内容不自动覆盖或重生。一次试运行只处理用户指定的集与组；源文档、压缩包及其他 Skill 的内容只作为参考数据，不自行扩大授权范围。

剧本是台词和情节的准稿。音频用于确定真实语速、气口及原音频中旁白和人物对白的时间位置。原音频中人物对白仅作时长参考，后续剪辑会移除这部分声音；本 Skill 不编辑音频，也不做最终成片。人物对白由剧梦视频节点生成语音和口型。

将工作分成可恢复的阶段，每阶段保存输入版本、产物、检查结果和状态。前一阶段未通过，不进入会消耗积分或改变剧梦项目的后续阶段。先按[任务边界与防污染](references/task-boundaries.md)确定本次任务类型，只读取当前阶段必需的参考；建立项目时读[项目事实与资产需求基线](references/project-baseline.md)。人物与场景资产、正式分镜、剧梦派生稿和海报各有独立输出标准，不能把某一类提示词或上一剧本的风格词带入另一类产物。

制作分镜时另读[分镜声画台账与检查顺序](references/storyboard-ledger.md)：逐集先建立独立原文声段清单，初稿和锁时稿分别核对；每集及合并后的多集稿都运行包内 `scripts/audit_storyboard.py`，并人工复核剧情与镜头组接。先让原文、声音、集组和镜头内容准确，再设计正反打与画面内转场；检查未通过的稿件不得交付或送剧梦。

制作场景或道具图片时另读[场景与道具资产制作规则](references/scene-prop-design.md)：纯场景只做空置空间，保持参考图所示的自然冷暖平衡，不带人物和独立道具；道具先按每集实际分镜出现次数筛选，单镜道具不为该集单独生图。独立道具图一图一件，无中文、logo、旗帜或国徽；不合格候选不得上传引用。

## 阶段

1. **剧本与资产台账**：明确实际读取的集、场和未覆盖范围；完整资产清单须覆盖声称的全部剧本范围。建立带原文位置的项目事实基线，分开记录已证实事实、设计推断、待核冲突及已批准资产。逐集先独立提取人物、场景、道具及需求优先级，再生成图片提示词；统一名称和别名，分开同一人物身份、固定视觉版本、临时服装／状态，以及同一场景身份、昼夜／回忆版本。区分实际出镜、屏幕／照片中可辨认、仅声音和仅提及；只为确有画面需求的对象准备图片。独立空间才新建场景，同一地点不同机位不自动算新场景，普通背景陈设不自动算独立道具。按剧本风格建立全剧视觉基准和本剧限定词；逐项适配用户给的限定词文档，记录采纳、改写和不适用项，不把另一剧本的真人风格、语言或光色要求直接套用。已有资产先检查可否复用，不盲目重生。
2. **资产图片**：仅为资产需求表中待制作项写对应类型的图片提示词，不把人物设定、纯场景和分镜动作混成一条。此阶段读取[人物设计参考](references/character-design-references.md)与[资产与引用交接](references/asset-handoff.md)。核对已批准身份、剧本定位与可用的脸部／服饰参考，男性角色追求俊朗、女性角色追求漂亮，同时保留各自辨识度与剧情所需年龄、体型和状态；仅在项目确认为水果人时按其拟人化果人风格转译，不照搬真人面孔。同剧人物检查脸型或造型轮廓、体型、服装辨识度；多视角只在资产确有需求时制作，不强制通用四视图版式。纯场景资产写清空间类型、动线或视觉层次、剧情锚点、时间光源及可行动区域，不混入无依据人物或水印。通过已安装并登录的剧梦 CLI 查询当前模型能力，使用用户指定的「九极 2.0 促销 3」生成。不要猜测 CLI 参数或模型标识。逐项核对名称、风格、同一人物跨状态的身份、必要视角、场景空间和道具细节，记录生成任务及图片路径。多视角资产要核对正、侧、背的同一身份、服装结构与完整性；布局参考只控制布局，不带入其人物外貌。人物脸与服装分别验收，场景检查空间关系，道具检查结构和剧情用途。向用户展示候选和检查结论，**只有用户确认合格后**才上传并建立剧梦引用；不合格图片不得冒充正式引用。分别记录候选、已批准、已上传、已保存引用映射状态，不能把上传成功当作引用完成。
3. **音频与分镜**：此阶段读取[分镜规则](references/storyboard-rules.md)、[多集分镜质量门禁](references/storyboard-quality-gate.md)和[限定词与人物保形规则](references/prompt-constraints.md)。先按剧本写分镜初稿，尤其一次生成多集时，逐集逐镜检查七栏的占位符、漏填、复制粘贴与无依据重复；不合格时从原剧本重新生成受影响集的分镜并重验，不能把占位符留给后续阶段。每镜指定一个主要画面任务，并核对人物站位、视线、手中物、动作进度与空间方向的跨镜承接；屏幕内容镜头写清观看者和合理机位。合格后再逐句听辨或对齐每集音频，区分旁白、原音频中的人物对白、气口。保留原文、原旁白语速及事件顺序；音频与剧本有差异时以剧本为准并记录差异。内部声音台账记录每句时间与镜头覆盖关系，不能用全片比例缩放冒充逐句锁时。逐镜分配时长并按自然气口分组；对白生成所需时长若超出参考，延长总体时长并重排后续镜头，不截词。正式分镜逐镜严格使用七栏「人物、场景、情节、画面、微表情、动作、台词」；音效写在相关栏内，不另增栏。
4. **剧梦提交**：此阶段读取[资产与引用交接](references/asset-handoff.md)、[逐处内联资产引用](references/inline-references.md)、[限定词与人物保形规则](references/prompt-constraints.md)和[节点提交与恢复](references/submission-recovery.md)。一组对应一个分镜节点；源文档的集组编号不自动等于剧梦选集或节点编号，先建明确映射。从正式分镜派生节点提示词：本剧限定词放在全文最前且只放一次，保留画面与人物对白，移除旁白文字及发声指令；旁白专属镜头的「台词」栏写「无台词」。本项目旁白 MP3 只用于锁时。先按角色身份与剧情时间／服装状态确定本镜应选的**已批准形象 ID**；在每个镜头正文的可见人物、场景和独立道具提及处插入真实剧梦资产标签，像界面标签一样逐处引用。组头对照表、组级绑定和镜头前的资产清单仅作核对，不能替代正文内联标签；「台词」原文保持纯文本。回读最终富文本，逐处核对身份、版本、类别和形象 ID，尤其是回忆与现时、男主与男二的切换；不明或错绑即停在提交前。检查无姓名嵌套、未选择占位、重复标签或截断，并核对平台字符上限。视频使用九梦 2.5 Pro、480p、9:16，节点秒数为该组实际时长；以 CLI 当前能力为准，不暗中换模型。提交前核对项目、集、组、限定词、每处引用、提示词、时长及预计积分。提交后记录任务 ID 和入队证据；状态不明先查询，不重复提交。
5. **视频验收**：此阶段读取[验收规则](references/acceptance.md)。等待每个节点完成并预览，检查人物身份、原有脸型与固有颜色、服装和体型、场景道具、剧情顺序、动作与表情、对白原文和说话人、口型、无旁白生成、时长及组间连续性。特别检查惊惧、愤怒等情绪镜头是否把角色整张脸或头发变成异常颜色、改变五官或产生其他身份漂移；出现此类画面即判失败。失败时记录具体问题并停止；**不自动重生成或额外扣积分**。只报告已实际生成且验收通过的视频。当前范围到剧梦生成和验收为止，不下载或剪辑，除非用户另行要求。

**可选海报分支**：用户要求封面或宣传海报时，在相关人物形象已批准后按[海报制作与验收](references/poster-workflow.md)执行。先用项目事实确定单一宣传卖点、人物关系与构图，再基于已批准的身份图和本剧视觉体系制作提示词及候选图；向用户展示并记录验收结果。海报独立于七栏分镜和视频节点，不把海报中的象征性构图当作剧情事实，也不因此自动增加视频生成范围或重复消耗积分。

## 状态与完成条件

资产按 `待制作 / 候选 / 待用户确认 / 已批准 / 已上传 / 已保存引用 / 失败` 分别记状态；视频节点按 `待准备 / 已就绪 / 已提交 / 生成中 / 已完成待验 / 通过 / 失败` 记状态。保存可追溯的项目、任务、文件、源文本和形象 ID。恢复时先检查源文件版本与远端状态，避免重复上传或生成；「已提交」「已完成」「验收通过」不能混写。

完成报告包含本次集组、资产批准状态、分镜版本、每个节点的实际时长与模型、生成与验收状态、问题、积分记录及剧梦项目链接；若要求海报，另列海报候选版本、批准状态和生成积分。试运行只在指定组全部通过后宣布通过；任何关键条件无法验证时明确写「未验证」。
